<summary><b>🔬 Computational pathology — technical details</b></summary>

- **Research problem:** Quantify pathology burden across large microscopy images and anatomical regions.
- **Engineering:** Tile sampling, segmentation training and inference, coordinate registration, and spatial quantification.
- **Scale:** Historical work involved multi-terabyte microscopy collections.
- **Scientific boundary:** Public code is an independent reconstruction; reported historical metrics are not a newly reproduced benchmark.

[Source code and methodology](https://github.com/sruthicodesthings/computational-pathology)

</details>

<details>
<summary><b>🏥 ICU prediction — technical details</b></summary>

- **Research problem:** Estimate subsequent ICU-transfer risk from hospital data available at a defined prediction time.
- **Engineering:** Cohort construction, feature availability audits, patient-level validation, model comparison, calibration, and exploratory competing-risk models.
- **Product demonstration:** Streamlit frontend for research exploration.
- **Scientific boundary:** Retrospective research, not a deployed or clinically validated decision-support system; MIMIC-IV data is access-controlled.

[Source code and methodology](https://github.com/sruthicodesthings/mimic-iv-icu-prediction)

</details>
